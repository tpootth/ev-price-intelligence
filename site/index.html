The workflow

From raw records to a measured claim.

Prepare
Vehicle features, not IDs

Drop identifiers and geographic fields. Encode make, model, vehicle type and eligibility; add year and make–model–year interactions. Handle missing values using training-fitted transformations.

Compare
Baseline, tuning, refinement

Start with a dense network, run 12 Bayesian tuning trials and refine the selected architecture. Choose the final weights using validation MAE before evaluating the test rows.

Interpret
Know the target

The supplied target is “Expected Price ($1k)”. Its construction and original source have not been verified. The result is a coursework experiment, not a validated used-car valuation service.

Reproducibility and data handling

The explorer publishes 344 aggregated make–model–year–type groups. Raw records, VIN prefixes, locations and vehicle IDs are excluded. The model is not executed in this browser. All evaluation values come from the saved Keras/PyTorch notebook.
